# لوحة الاستثمارات (Investment Portfolio Dashboard)

تطبيق ويب ثابت (HTML/CSS/JS بلا أدوات بناء) بواجهة عربية RTL، يعمل على الكمبيوتر والهاتف، مع وضع فاتح/داكن.
البيانات تُحفظ على جهازك فوراً، وتُزامَن اختيارياً مع **جدول Google Sheets خاص بك** عبر **Google Apps Script**.

## البنية التقنية ولماذا

| الطبقة | الاختيار | السبب |
|---|---|---|
| الواجهة | ملفات ثابتة (`index.html` + `js/` + `css/`) | تُنشر مجاناً على أي استضافة ثابتة، بلا خادم تديره |
| الحسابات | `js/calc.js` (منطق مركزي بلا واجهة) | يُختبر في Node؛ متوسط مرجح WAC وقابل للتوسعة إلى FIFO (مُنفَّذ أيضاً) |
| الحفظ المحلي | `localStorage` + قائمة عمليات معلّقة | يعمل دون اتصال ولا تضيع التغييرات |
| الخلفية | Google Apps Script مرتبط بجدول Sheets | لا خادم ولا تكلفة؛ البيانات في حسابك أنت |
| الدخول | Google Sign-In (ID token) | الخادم يتحقق من التوقيع و`aud` وأن البريد = بريدك فقط |

**الأمان:** لا كلمات مرور ولا أسرار في المتصفح. الموجود في الواجهة هو *Client ID* فقط (معرّف عام بطبيعته).
مفتاح الأسعار (اختياري) يُحفظ في Script Properties على الخادم. الصلاحية المطلوبة للسكربت: `spreadsheets.currentonly` أي هذا الجدول فقط وليس كل Drive.

**المزامنة:** كل تغيير يُرسل كعملية بمعرّف فريد، فإعادة المحاولة لا تكرره. التعارض: آخر تعديل يفوز لكل سجل. الحذف «ناعم» (لا يُمحى السجل ماديّاً)، وكل تغيير مالي يُسجَّل في ورقة `Audit`.

## التشغيل محلياً (فوراً، بلا أي إعداد)

```bash
cd portfolio
python3 -m http.server 8080      # أو: npm start
# افتح http://localhost:8080
```
يعمل بوضع «محفوظ على هذا الجهاز فقط». استخدم **استيراد وتصدير ← نسخة احتياطية** بانتظام في هذا الوضع.

## ربط Google (للمزامنة بين الهاتف والكمبيوتر)

لا أملك صلاحية دخول حساباتك، لذا هذه الخطوات تنفّذها أنت (≈15 دقيقة):

**1) أنشئ الجدول والسكربت**
1. في Google Drive أنشئ Google Sheet فارغاً باسم «Investment Portfolio DB».
2. من القائمة: **الإضافات ← Apps Script**.
3. احذف المحتوى، والصق محتوى `backend/Code.gs`.
4. من ⚙ **Project Settings** فعّل «Show appsscript.json» والصق محتوى `backend/appsscript.json`.

**2) أنشئ OAuth Client ID**
1. افتح [Google Cloud Console](https://console.cloud.google.com) ← أنشئ مشروعاً.
2. **APIs & Services ← OAuth consent screen**: النوع External، أضف بريدك مستخدماً تجريبياً (Test user).
3. **Credentials ← Create credentials ← OAuth client ID ← Web application**.
4. في **Authorized JavaScript origins** أضف عنوان موقعك بالضبط (مثل `https://اسمك.github.io` و`http://localhost:8080` للتجربة).
5. انسخ **Client ID** (ينتهي بـ `.apps.googleusercontent.com`).

**3) اضبط الخصائص السرية في Apps Script**
Project Settings ← Script properties:
- `CLIENT_ID` = الـ Client ID أعلاه
- `OWNER_EMAIL` = بريدك في Google
- `PRICE_API_KEY` = (اختياري) مفتاح Finnhub

**4) انشر السكربت**
**Deploy ← New deployment ← Web app**: Execute as = *Me*، Who has access = *Anyone*.
(كل طلب يُرفض ما لم يحمل توكن Google صالحاً لبريدك، فالوصول المفتوح هنا لا يكشف شيئاً.)
وافق على الصلاحيات عند أول مرة، ثم انسخ رابط `/exec`.

**5) اربط الواجهة**
افتح التطبيق ← **الإعدادات ← الربط مع Google**، ألصق الـ Client ID والرابط وسجّل الدخول.
(أو ضعهما في `config.js` قبل النشر ليعملا على كل أجهزتك.) كرّر على الهاتف بتسجيل الدخول نفسه.

> عند تعديل `Code.gs` لاحقاً: Deploy ← **Manage deployments** ← تعديل ← Version جديدة (الرابط يبقى نفسه).

## النشر على الإنترنت
أي استضافة ثابتة: **GitHub Pages** أو **Cloudflare Pages** أو **Netlify** (مجانية). ارفع محتوى مجلد `portfolio` كما هو (لا بناء). ثم أضف عنوان الموقع إلى Authorized JavaScript origins (الخطوة 2.4). على الهاتف: «إضافة إلى الشاشة الرئيسية».
بيانات مالية خاصة: المستودع/الموقع يحوي **الكود فقط**؛ بياناتك لا تُنشر معه أبداً.

## الأسعار وأسعار الصرف
- **الأسهم:** تعمل بالإدخال اليدوي دائماً. التحديث التلقائي اختياري للأسهم الأمريكية عبر Finnhub (توجد خطة مجانية محدودة، والبيانات قد تكون متأخرة حسب الخطة). **لا يوجد مصدر مجاني رسمي لسوق مسقط**؛ أدخل أسعاره يدوياً أو اربط مزوّد اشتراك لاحقاً عبر `Prices.providers` في `js/prices.js` (طبقة مستقلة).
- كل سعر يظهر بحالته: لحظي / متأخر / مدخل يدوياً / قديم، مع وقته. السعر القديم لا يُعرض لحظياً.
- **الصرف:** تحديث من البنك المركزي الأوروبي (frankfurter.app، مجاني، يومي)، والريال العماني مربوط بالدولار (0.3845). أو إدخال يدوي. سعر الصرف يُسجَّل مع كل عملية فلا تتغير نتائج الماضي.

## هيكل البيانات (أوراق Sheets)
`Investments` (سجل لكل استثمار) ← 1:N ← `Transactions` (شراء/بيع/دخل/استرداد/رسوم؛ تحمل `invId`، العملة، `fxRate`)،
و`Fx` و`Prices` و`Snapshots` (لقطات يومية للقيمة السوقية) و`Settings` و`Audit`. كل الأرصدة والأرباح **تُحسب** من العمليات ولا تُخزَّن، فلا تختلف الأرقام أبداً عن السجل.

## ملاحظات منهجية
- العائد المعلن للصك/السند تقديري وليس مضموناً؛ «المتوقع المتبقي» منفصل عن «المستلم فعلياً».
- أي مؤشر ينقصه بيانات يظهر «غير متاح» (مثل غير المحقق دون سعر، وXIRR لفترة أقل من 30 يوماً).
- العائد الإجمالي = محقق + غير محقق + مستلم − رسوم، بدون احتساب مزدوج.
